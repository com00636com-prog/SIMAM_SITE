§ 01 The Dual Crisis

A perimeter of billions, drawing power from a planet that can no longer afford it.

IoT proliferation has created a single problem with two faces: an attack surface that grew faster than defensive tooling, and an energy footprint that grew faster than the grids supplying it. SIMAM refuses the trade-off between the two.

Every redundant packet sent to the cloud is a carbon transaction. Every undetected anomaly at the edge is a security debt. SIMAM settles both at the silicon, before either has a chance to compound.

The threat surface.

Traditional IDS solutions carry computational overhead incompatible with edge constraints. The result: most perimeter devices ship without on-device detection, defended only by upstream cloud filters that react after the payload has already traversed the network.

§ 02 Integrated Architecture

A dual-engine pipeline, orchestrated by an ambient-aware controller.

Raw telemetry is cleaned, filtered, and scaled, then routed through a low-power anomaly filter that only wakes the deep classifier when reconstruction error crosses an adaptive threshold. Most traffic never touches the heavy model. That is the entire trick.

محرّكان. الأول يصمت ما هو طبيعي. الثاني يستيقظ فقط عند الشكّ.

Stage 01 Telemetry Capture Raw IoT packets from noisy wireless channels — dropouts, missing indices, and signal anomalies all accepted as input without preprocessing assumptions. ingest // line-rate · zero buffering
→
Stage 02 Mathematical Filtering Linear interpolation restores missing samples. A cascaded Kalman + Savitzky-Golay filter suppresses jitter while preserving the sharp peaks characteristic of low-and-slow attacks. Kalman ∘ S-G ∘ Robust Scaler
→
Stage 03 LA-IDM Anomaly Filter Lightweight autoencoder with a 32-neuron bottleneck. Reconstruction MSE is benchmarked against an adaptive threshold. Benign traffic exits here without ever waking the Q-CNN. unsupervised // 32-dim latent
→
Stage 04 1D Q-CNN Triggered only on anomaly. Performs explicit multi-class classification — botnet, port scan, brute-force, injection — at 8-bit integer precision on bare metal. INT8 quantized // Arduino-class

Lab · A The fuzzy controller, opened up

Three readings in. One decision out: how hard to look.

SIMAM never runs its detector at a fixed intensity. A fuzzy-logic controller reads the current threat score, the battery level and the network load, and decides how much of the pipeline to wake. § 03 The LA-IDM, Visualised

    Preprocessing · four stages

    §4.2 · validation → imputation → noise reduction → scaling · paper

    1 · ValidateOut-of-range values, mixed types and duplicate timestamps filtered before learning.
    2 · ImputeGaps filled by linear interpolation to keep the time series continuous.
    x̂t = xt−k + (t − (t−k)) · [ xt+1 − xt−k ] / [ (t+1) − (t−k) ]linear interpolation between the nearest known samples
    3 · DenoiseThree-tier: moving average and Kalman for general jitter; Savitzky–Golay prioritised because it preserves peak shape — the signature of low-and-slow attacks.
    4 · ScaleRobust (IQR) scaling so bursty outliers do not dominate the input range.
    x′ = ( x − median(x) ) / ( Q3(x) − Q1(x) )robust scaling · interquartile range as the unit

    Detection, control and energy equations

    §5.2 · §6 · §7 · §8 · paper

    z = σ(Wex + be)    x̂ = σ(Wdz + bd)
    L(x, x̂) = (1/n) Σ (xi − x̂i)²    S(x) = L(x, x̂)LA-IDM · 32-neuron bottleneck · anomaly score is the reconstruction MSE (run it in Lab B)
    Q(x) = clip( round(x / s), −2b−1, 2b−1−1 )    s = max(|xmax|,|xmin|) / (2b−1−1)symmetric INT8 quantisation, b = 8 · the same rule used for the browser model
    Pintensity = Σ μi·pi / Σ μifuzzy controller · centre-of-gravity defuzzification over Minimal / Normal / Enhanced (Lab A)
    E = α·Ctotal + β·Maccess + γ·tcomputehardware energy model · compute, memory-access and execution-time terms with platform coefficients
    Accuracy = (TP+TN)/(TP+TN+FP+FN)   Precision = TP/(TP+FP)   Recall = TP/(TP+FN)   F1 = 2PR/(P+R)evaluation metrics · reported per feature group; SMEESI 93.7–94.5% across all four

    Controller · operating modes

    §6.2–6.3 · inputs Tlvl, Blvl, Nload · triangular and trapezoidal membership · paper

    MinimalLA-IDM only. Basic anomaly filtering for low-risk periods; the Q-CNN stays powered down.
    NormalBalanced operation with moderate inference cost; classifier on standby.
    EnhancedFull-spectrum detection, Q-CNN + LA-IDM. The security override: engaged whenever threat is high, regardless of battery level.
    ConditionAction
    Tlvl = Low ∧ Blvl = LowMinimal
    Tlvl = Medium ∧ Blvl = NormalNormal
    Tlvl = High (any Blvl)Enhanced — security override

    Deployment stack and what comes next

    §7.1 · §10 · paper

    TargetArduino Nano 33 BLE Sense · ARM Cortex-M4 at 64 MHz · 256 KB SRAM · 1 MB flash.
    RuntimeTensorFlow Lite for Microcontrollers; mandatory 8-bit fixed-point quantisation across every layer.
    FeedbackEnergy feedback loop from the FLC to the inference engine, so intensity follows battery telemetry in real time.
    ToolingPython · Keras / TensorFlow Lite · scikit-learn · Dash / Plotly dashboard for energy and threat telemetry.
    Future iFederated learning across heterogeneous edge fleets — generalise without centralising telemetry.
    Future iiPhysical-layer side-channel signals as additional controller inputs.
    Future iiiFormal verification of the fuzzy rule base for provable safety under adversarial conditions.
